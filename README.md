# Graph-Theory-Divide-and-Conquer-for-TSP

Graph Theory Performance Innovative Task: **Algorithm 2.8, Divide and Conquer for the TSP** (Luna-Garcia, Candano & Caga-anan, *The Mindanawan Journal of Mathematics* 6(2), 2024), applied to a one-day city tour of Cagayan de Oro City that starts and ends at USTP.

| Folder | Contents |
| --- | --- |
| [`code/`](code/) | Python implementation, dataset (`code/data/`), tests. See [code/README.md](code/README.md). |
| [`latex/report/`](latex/report/) | Written report (LaTeX). |
| [`latex/presentation/`](latex/presentation/) | Slides for the 10–15 minute video (LaTeX beamer). |
| [`latex/shared/`](latex/shared/) | Bibliography and the tables/figures generated by the code. See [latex/README.md](latex/README.md). |
| `article and instructions/` | The assigned paper and the task instructions. |

Quick start:

```powershell
cd code
python main.py                  # run the demo
python main.py --export-latex   # refresh the report/slide tables and figures
```

Then build `latex/report/main.tex` and `latex/presentation/main.tex` in VS Code (`Ctrl+Alt+B`).
